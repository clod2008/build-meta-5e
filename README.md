# Build Meta 5e

Elegí raza y clase de D&D 5e y mirá qué tan alineado está el combo (0 a 10), comparando los bonos de característica clásicos del PHB contra lo que cada clase pesa más. Fondo animado en WebGL (mapa con niebla en movimiento). Sigilos e ilustraciones propios, sin arte oficial de Wizards of the Coast.

Ejercicio del módulo de código de la Diplomatura en IA.

Sitio estático de un solo archivo (`index.html` + `Assets/`), sin build ni dependencias — se despliega directo.
